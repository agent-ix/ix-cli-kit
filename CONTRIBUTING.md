# Contributing

Read the [canonical Agent IX CLA](CLA.md) and the [content rights policy](CONTENT_RIGHTS.md)
before submitting a contribution. External material needs recorded provenance,
compatible distribution rights, and human approval as described in that policy.

For an outside contribution, the CLA assistant requests an electronic signature
with your legal name on the pull request. Signatures are recorded per repository.
Follow [the Rust conventions](.agent/rules/writing_rust.md), keep changes focused,
and run `make ci` before submitting a pull request. Native OS credential tests are
opt-in; ordinary tests use synthetic credentials and injected backends.

Report bugs or request features through [GitHub issues](https://github.com/agent-ix/ix-cli-kit/issues).
For community questions, join [Agent IX on Discord](https://discord.gg/k8DVhuYBR2).
